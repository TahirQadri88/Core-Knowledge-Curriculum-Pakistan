# Core Knowledge Ledger

An offline web app (PWA) for Karachi families to track Core Knowledge units (Kindergarten to Grade 8), school textbook chapters, and character and deen goals for each child.

- Live app: `docs/` (served by GitHub Pages)
- Source: `src/app.html`, `src/data.js`
- Build: `python3 build.py`
- Test: `python3 scripts/test_app.py`
- Check unit links: `python3 scripts/check_links.py`

See `CLAUDE.md` for how the project is organised and the rules for changing it, and `notes/` for the verification record.

Not affiliated with the Core Knowledge Foundation or Oxford University Press. Core Knowledge materials are free to download from coreknowledge.org under the Foundation's terms.
